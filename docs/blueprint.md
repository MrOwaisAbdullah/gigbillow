# **App Name**: ProManFlow

## Core Features:

- Project Management: Create, edit, and manage multiple projects.
- Time Tracker: Track work hours for each project with a built-in time tracker.
- Automated Invoice Generation: Automatically generate invoices based on tracked hours, with options for customization.
- Platform Integration Tool: A tool for importing completed work information across platforms like Fiverr and Upwork in order to populate invoices.
- Invoice Dashboard: Dashboard to view all generated invoices with their status (paid, unpaid, overdue).
- Client Management: Maintain client information including contact details and billing preferences.
- Reporting: Generate reports on project time, revenue, and outstanding invoices.

## Style Guidelines:

- Primary color: Teal (#008080) for a modern, professional look.
- Background color: Light gray (#F0F0F0) for a clean, neutral base.
- Accent color: Dark gray (#4A4A4A) for contrast and highlights.
- Body and headline font: 'Inter', a sans-serif, for a modern and objective feel.
- Use simple, geometric icons to represent projects, time tracking, and invoices.
- Clean, grid-based layout to ensure content is well-organized and easy to navigate.
- Subtle transitions and animations on UI elements for a polished user experience.
